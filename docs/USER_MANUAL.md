# 用户手册

## 1. 安装与启动

### 系统要求

- Windows 10/11 x64
- Microsoft Edge WebView2 Runtime（系统通常自带；缺失时从微软官网安装）
- 建议 8GB 以上内存；10 万本书库建议 SSD

### 运行

1. 解压发布包到任意可写目录（不要放在受保护的 Program Files）。
2. 双击 `MoonAot.exe`。
3. 首次启动会在 exe 同目录创建 `data/`；所有书库、设置、封面、笔记都在这里。

程序是便携式：换电脑时复制整个目录（含 `data`）即可。

## 2. 书架

- **导入书籍**：左上角“导入书籍”支持文件、文件夹、拖拽；也可把文件拖到窗口。
- **虚拟滚动**：10 万本书也只渲染可视区域，滚动流畅。
- **排序**：最近阅读、导入时间、书名、作者、文件大小、格式。
- **筛选**：全部/在读/未读/已读/收藏；格式、作者、文件夹。
- **搜索**：书架顶部搜索框按书名/作者/文件夹模糊匹配。
- **封面**：右键书籍可更换封面；无封面时显示渐变书脊或缺省封面。
- **书籍菜单**：打开、详情、收藏、重命名、更换封面、删除、在文件夹中显示。
- **详情**：查看路径、格式、大小、进度、简介、笔记数量。

### 大库首次启动说明

- 新版首次启动会在后台：
  1. 建立/升级 SQLite 索引；
  2. 把历史超大封面压到 ≤48KB，并清理旧版书籍缩略图（书架直接使用封面）；
  3. 若开启“导入时提取封面”，后台补齐 EPUB/PDF/MOBI/AZW3 缺失封面。
- 这些任务不阻塞书架；补齐过程中新封面会分批出现。TXT 不提取封面，使用书脊占位。
- 可在“设置 → 维护”或“统计”页点击“重建封面”手动触发。

## 3. 阅读器

支持 TXT、EPUB、PDF、MOBI、AZW3、Markdown。

- 双击书架中的书打开；阅读器窗口内按 `↑` / `↓` 按书架当前筛选与排序切换上一本/下一本（例如只切换当前文件夹/作者/格式内的图书）。
- `Esc` 关闭阅读器；`F11` 全屏（以阅读器内设置为准）。
- 目录、主题、字体、字号、行距、页边距、进度、笔记、书签均在阅读器侧栏/设置中。
- 阅读进度自动保存；再次打开回到上次位置。
- EPUB 兼容：自动修复容器 OPF 路径大小写不一致的电子书（首次打开会生成 `data/cache/epub/` 副本）。
- PDF 使用内置 pdf.js 渲染；TXT/MD 自动识别 UTF-8/UTF-16/GB18030。
- 阅读器不加载任何在线字体，断网也能立即打开。

## 4. 媒体库

左侧“媒体库”提供文件浏览、收藏文件夹、最近媒体。

### 图片浏览器

- 打开图片或文件夹；文件夹递归扫描子目录。
- 底部缩略图栏 + **可拖动滑块**：拖动滑块即时切换到对应图片。
- 工具栏：上一张/下一张、放大/缩小、显示模式、旋转、幻灯片、漫画模式、编辑、信息、全屏。
- 显示模式：自动居中 / 适应窗口 / 适应宽度 / 适应高度 / 原始大小，选择会持久化。
- 全屏（按钮或 `F11`）：只显示图片，隐藏标题栏、缩略图与设置；`Esc`/`F11` 退出。
- 幻灯片设置：间隔 0.1–60 秒、过渡效果（淡入/滑动/缩放/无）、循环、背景音乐。
- 背景音乐支持选择单个文件或递归导入音乐文件夹；文件夹与曲目索引会保存。
- 缩放和旋转按文件夹记忆；下次打开同一文件夹自动恢复。
- 未指定路径启动时，自动打开上次浏览的文件夹。
- **右键图片**：
  - 编辑图片
  - 复制图片路径
  - 在文件夹中显示
  - 图片信息
- **图片编辑器**：
  - 左/右旋转 90°、水平/垂直翻转
  - 拖拽框选裁剪
  - 亮度/对比度/饱和度、黑白/怀旧/反色
  - 缩放比例
  - 撤销/重做/重置（`Ctrl+Z` / `Ctrl+Y`）
  - 保存副本（`Ctrl+S`）或确认后覆盖原图
  - 输出 PNG 或 JPEG(92%)

### 音乐播放器

- 打开文件/文件夹：递归收集音频并生成播放列表。
- 播放列表、顺序/单曲/随机、上一首/下一首、进度与音量记忆。
- 歌词：本地 `.lrc`、在线 lrclib 搜索、内置歌词面板。
- 背景轮播：点击顶部图片按钮打开设置面板，可选择文件夹、0.1–60 秒间隔、上一张/下一张、随机播放、显示方式（铺满/包含/拉伸/原始居中）、磨玻璃强度 0–10；设置会持久化。
- 切换“载入已保存播放列表”时，曲目列表、当前曲目和标题会同步更新。
- 顶部菜单会自动换行，窄窗口下按钮不会被截断。

### 视频播放器

- 递归收集视频，生成播放列表。
- 支持常见格式（依赖 WebView2/Chromium 解码）；音量、进度、播放列表状态记忆。

### 压缩包

- 内置 zip/cbz 浏览、解压、预览图片；双击条目用内置查看器打开。

## 5. 全盘搜索

左侧“全盘搜索”，基于 NTFS MFT 与 USN 实时索引。

- 首次启动自动为固定盘/移动盘建立索引；任务栏显示各盘状态与条目数。
- 搜索语法（空格为 AND）：
  - `报告 2024`：同时包含两个词
  - `jpg|png`：或
  - `!临时`：排除
  - `"完整短语"`
  - `ext:epub`、`ext:jpg|png`
  - `size:>10mb`、`size:<1kb`
  - `dm:2024`、`path:图书`、`parent:下载`、`folder:`、`file:`
  - `regex:^第.*章$`
- 支持按名称/路径/大小/类型/修改时间排序，列宽与设置持久化。
- 双击/右键“打开”：按文件类型用内置阅读器、播放器、浏览器或系统程序打开。
- 设置：启用盘符、排除目录、仅包含目录、重建索引、定时重扫。
- 支持 U 盘/移动硬盘热插拔；非 NTFS 盘自动使用文件系统监控。
- “打开所有”：把结果中的音频/视频/图片分别送入对应播放器（最多取每种第一个）。

## 6. 维基百科（ZIM）

- 左侧“维基百科” → “打开 ZIM 文件”，选择 `.zim` 离线包。
- 支持标题搜索、随机条目、前进/后退、简繁转换。
- 全盘搜索中双击 `.zim` 会自动加载并跳到维基页面。
- ZIM 最近文件记录在 `data/zim_recent.txt`。

## 7. 浏览器

- 多标签、地址栏、前进/后退/刷新/主页、历史、收藏。
- 页面翻译（MyMemory）、代码注入、开发者工具。
- 可把本地 HTML 文件用内置浏览器打开（搜索/媒体库双击 `.html`）。

## 8. 工具箱 / 网站工具

- 进程列表与结束进程、端口占用与结束、系统信息、磁盘信息。
- 全屏截图（保存到 `data/screenshots`）。
- 电源：锁屏、关屏、睡眠、休眠、立即关机/重启、定时关机/重启、取消定时。
- 压缩/解压、哈希计算。
- 网站工具：抓取站点到本地、托管 `/site/{id}`、下载资源、任务队列。

## 9. 按键精灵

- 录制键盘/鼠标、编辑步骤、循环、延迟、鼠标移动/点击/滚轮、文本输入。
- 支持组合键与宏热键；宏保存在 SQLite。
- 示例：拳皇连招
  ```
  s sd  d 延迟200ms ik 延迟50ms k k k
  ```
- 每条步骤可单独调整保持时间与延迟；支持启用/禁用、排序、删除。

## 10. 代码与文档查看器

- **代码编辑器**：JSON/CS/C++/Python/JS/TS/Java/Go/Rust/PHP/XML/CSS/SQL/YAML/INI/SH 等。
  - CodeMirror 6 语法高亮、行号、搜索、撤销重做
  - `Ctrl+S` 保存，保持原编码（UTF-8/BOM/UTF-16/GB18030）
- **Word**：`.docx` 渲染（docx-preview），缩放。
- **表格**：`.xlsx/.xls/.csv`，多工作表、行号、超大表截断保护。
- **PPT**：`.pptx` 渲染（pptx-preview），列表模式、缩放。
- **3D**：`.fbx/.obj/.glb/.gltf/.stl/.3ds/.dae/.ply/.3mf`，轨道旋转、自动旋转、线框。
- **CAD**：`.dxf` 二维线框，缩放/平移/适应窗口。

## 11. 快捷键

| 场景 | 快捷键 |
|---|---|
| 图片浏览器 | `←/→` 上一张/下一张，`+/-` 缩放，`0` 适应，`R` 旋转，`空格` 幻灯片，`Home/End` 首/尾，`F11` 全屏，`Esc` 关闭 |
| 图片编辑器 | `Ctrl+Z` 撤销，`Ctrl+Y` 重做，`Ctrl+S` 保存副本，`Esc` 关闭 |
| 代码编辑器 | `Ctrl+S` 保存，`Esc` 关闭 |
| 阅读器 | `↑/↓` 切换书籍，`Esc` 关闭（以阅读器内设置为准） |

## 12. 数据备份与迁移

备份整个 `data/`：

- `moonaot.db`：书库与设置
- `covers/`：封面
- `thumbs/`：无封面标记与媒体缩略图（旧书籍缩略图会被自动清理）
- `library/`：网页上传的书籍副本
- `cache/epub/`：EPUB 修复缓存（可删除）
- `tiny-settings.json`：全盘搜索设置
- `logs/`：日志（排查问题）

迁移到新电脑：复制程序目录 + `data/`，安装 WebView2 Runtime 即可。书库记录的是原始文件路径；若书籍文件位置变化，可在书架详情查看原路径或重新导入。

## 13. 常见问题

**启动后书架空白/书籍缺失**：书籍只登记原始路径；移动/删除原文件会标记“文件缺失”。可在“设置 → 维护”清理失效记录。

**封面一直不出现**：确认“导入时提取封面”开启；TXT 无封面；PDF/EPUB 提取失败的书会写 `.none` 标记，执行“重建封面”可重试。

**打开某些 EPUB 一直转圈**：新版已自动修复 OPF 路径大小写；若仍失败，查看 `data/logs/app.log` 中的 `EPUB 兼容修复失败` 或 `Failed to load package document`。

**全盘搜索没有结果**：查看搜索页顶部各盘状态；首次索引需要时间；NTFS 卷读取 MFT 需要管理员权限，失败会自动回退递归扫描。

**阅读器字体与预期不同**：为避免网络阻塞，阅读器不再加载在线字体，使用系统字体与内置字体；可在阅读器设置中调整字体族。

**占用空间大**：`data/thumbs`、`data/covers`、`data/cache` 可安全删除，程序会按需重建；删除 covers 后启动会自动清空失效封面引用并后台重新提取。不要删除 `moonaot.db`。
