# 药品说明书数据说明（v1.2.0）

## 数据来源

- 目录：`D:\code\ps2gameagent\药品说明书数据库_医药数据查询\`
- 文件：`file1.xlsx` … `file7.xlsx`
- 原始行数：**114,335** 行（有效通用名 114,072 行）

## 去重规则

1. 以「通用名称（含剂型）+ 含量」为键：
   - 通用名做 NFKC，去空白与括号全半角归一；
   - 从规格中提取质量/体积/单位（mg、g、μg、ml、IU、万单位、% 等）作为含量键，忽略包装数量（如 `0.25g×24粒` 与 `0.25g×50片` 视为同一含量）。
2. 同一键下保留“最长的说明书”：按适应症、用法用量、药理作用、禁忌、不良反应、注意事项、相互作用、药代动力学、成份、性状、特殊人群用药等正文字段长度之和评分，取最高者。
3. 去重结果：**32,784 种**说明书。

## 写入位置

- 数据库：`<exe目录>\data\medical.db` → `med_concepts`
- 字段：
  - `type = leaflet`
  - `category = 药品说明书`
  - `source = drugdata`，`source_version = 2021-05-17`
  - `data_json` 字段（中文键）：通用名、商品名、汉语拼音、批准文号、药品分类、生产企业、药品性质、相关疾病、性状、主要成份、适应症、规格、不良反应、用法用量、禁忌、注意事项、孕妇及哺乳期妇女用药、儿童用药、老人用药、药物相互作用、药理作用、药代动力学、贮藏、有效期、来源。
- 分类标签：`med_tags` → `tag-药品说明书`；每条说明书写入 `med_tagged`，用于分类计数与筛选。
- 导入前备份：`data/medical.db.bak-before-leaflets-20261105`（未导入前的库）。

## 界面

- 搜索或空关键词 + 类型“说明书”/分类“药品说明书”浏览。
- 点击卡片打开专用说明书阅读界面：左侧目录（适应症、用法用量、药理作用、禁忌、不良反应、注意事项、药物相互作用、药代动力学、规格、贮藏等），右侧章节正文。
- 说明书可通过右侧详情“编辑 / 删除”维护，编辑保存为本地用户修改，不影响原始 XLSX。

## 重新导入

1. 重新生成去重数据（脚本位于开发环境临时目录，规则见上）。
2. 运行导入脚本写入 `medical.db`；脚本以 `source='drugdata'` 先清理旧数据，再批量写入。
3. 重启 MoonAot，首次 `status` 会核对分类标签关系。

## 注意

- 原始数据来自第三方整理的说明书，可能滞后于最新版药监批准文本；界面已标注“仅供学习参考，不作为用药依据”。
- 规格中的多组含量（如 `0.5ml:20mg`）会合并为一个说明书条目，同名不同含量仍分开保存。
