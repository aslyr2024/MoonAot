# 医学助手使用说明

- 版本：v1.1.0（随 MoonAot v1.1.0 发布）
- 入口：MoonAot 侧栏 →「医学助手」
- 定位：**本地临床速查 + 医学书原文定位**
- 声明：仅供学习与资料检索参考，**不作诊断、处方或治疗依据**；全部离线，不上传任何内容。

---

## 1. 它解决什么问题

| 场景 | 用法 |
|---|---|
| 查疾病、症状、药品、检验、指南 | 直接搜索名称，先看「临床速查」卡片 |
| 想知道教科书里怎么写的 | 切到「原文段落」，点击结果跳回章节并高亮 |
| 只记得拼音首字母 | 输入 `xlsj`（心力衰竭）、`amxljn`（阿莫西林胶囊） |
| 按科室/分类找条目 | 左侧「临床分类」，无需输入关键词 |
| 记笔记、收藏、常用模板 | 检索卡片、精读页与「我的」页签 |

医学助手不是聊天机器人，不生成诊断结论，也不会联网补充知识。

---

## 2. 第一次使用

1. 打开侧栏「医学助手」。
2. 点右上角 **数据与设置 → 导入**。
3. 两种导入方式任选：
   - **内置资料**：显示本机是否存在西氏内科学上/中/下、胸腹部影像图解与 clinical JSON；点「导入检测到的内置资料」只会导入实际存在的文件。
   - **自己的书**：在「添加书籍 / Markdown」中浏览选择 `.epub` 或 `.md`，可填写卷次。
4. 等待底部显示索引完成（首次导入大书可能需要几十秒）。
5. 回到检索页，输入关键词或点击分类。

> 未找到内置资料时不会报错中断；缺失的条目会跳过。

---

## 3. 检索

### 3.1 输入方式

- 中文名称：`心肌梗死`、`高血压`、`阿莫西林`
- 两字词：`心梗`、`发热`（不依赖三分词索引，短词层会命中）
- 拼音首字母：`xlsj` → 心力衰竭；`fr` → 发热
- 多个词用空格：默认要求同时出现（AND）

### 3.2 结果区

- **临床速查**：结构化的疾病、症状、药品、检验、操作、指南、说明书卡片。点击卡片，右侧显示完整字段、书中出现位置与相关条目。
- **原文段落**：书内命中，显示书名/卷/章节与高亮片段。点击跳转到「精读」并定位到对应段落。
- **相关注释**：内容命中的个人注释，点击即可编辑。
- 原文段落支持「按相关度 / 按书内顺序」排序；结果较多时点底部「加载更多」。

### 3.3 筛选

- **类型筛选**：只看疾病、药品、检验等（可多选）。
- **临床分类**：按科室/资料分类浏览；点「全部」取消。
- **数据源**：点击左侧书籍可只看该书原文；与关键词一起使用更精确。
- **我的收藏**：只显示已收藏的概念与原文。

---

## 4. 精读与注释

- 点击原文结果进入「精读」：自动滚动到命中段，查询词与本章概念会高亮。
- 顶部可切换上一节/下一节、收藏本章、在静读阅读器中打开原书。
- 选中正文文字后点「＋ 注释」，会自动带上引用。
- 注释支持 Markdown；写 `[[急性心肌梗死]]` 会建立双链，概念详情的「反链」中可看到。
- 注释可在「我的 → 我的注释」中编辑或删除；删除前会确认。

---

## 5. 收藏、模板与检索式

- **收藏**：概念卡/章节/原文段落上的 ☆ 按钮；「我的 → 我的收藏」会显示可读标题，点击可回到对应内容。
- **模板**：
  - 「我的模板」中的模板点击可预览、删除。
  - 「内置模板库」含临床文书模板，点击预览后，点「另存为我的模板」才会复制，**不会自动复制**。
  - 可新建笔记/卡片/文书模板。
- **检索式**：把关键词、类型、分类组合保存下来；在「我的 → 检索式」中一键恢复。保存时使用当前搜索框旁的「保存检索式」。

---

## 6. 数据与设置

「数据与设置」分三页：

- **数据源**：书籍列表、路径、章节数、锚点重建率；可移除单本书（不删除原文件）。
- **导入**：内置资料检测、clinical JSON 目录选择、添加书籍/Markdown、药品说明书录入。
- **维护**：重建概念索引（通常不需要手动执行）、导出笔记/模板/检索式为 JSON、查看版本与帮助。

数据位置：

- 索引与个人资料：`<exe 同目录>\data\medical.db`
- clinical 快照：`data\medical\sources\clinical\<版本>`
- 原书文件只读，不会被修改或删除。

## 7. 快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl+K` | 聚焦搜索框 |
| `Ctrl+D` | 收藏当前概念/章节 |
| `Esc` | 关闭弹窗/建议列表 |

## 8. 常见问题

**搜不到内容？**
1. 打开「数据与设置 → 数据源」，确认书的状态为 `ready` 且章节数不为 0。
2. 只导入 clinical 数据时没有书籍原文，但临床卡片仍可检索。
3. 书籍文件被移动后路径会失效，需要重新导入。

**章节打开没有正文？**
- EPUB 依赖原文件路径，确认文件仍在原位置。
- Markdown 在 v1.1.0 已修复为按段落渲染；旧版本导入的 Markdown 建议重新导入。

**分类计数全为 0？**
- v1.1.0 首次打开会自动把旧数据中的概念挂到分类上；若仍为 0，重启一次应用或执行「维护 → 重建概念索引」。

**我的模板怎么没了？**
- 内置模板需预览后手动「另存为我的模板」；删除操作都会二次确认。

**数据会不会上传？**
- 不会。无联网检索、无云端模型，所有内容与笔记都在本机 SQLite。
